# Pac-Pen multiplayer

Local: `npm install && npm start`, then open http://localhost:3000 (open it in two tabs to test).
Share a private room with `?room=friends` on the URL.

Render: New > Web Service > connect the repo. Build `npm install`, Start `npm start`
(or use render.yaml). No environment variables are required; Render supplies PORT.
Set `UNIQUE_CHARACTERS=false` to let several players use the same character.
